discord bot the checks the status of the game lifetime and sends messages to the discord channel every time the game has a new update. 
You can also connect to your database and it will make the product you’re selling unavailable until a new update is available and will freeze the active keys if you’re selling it with license keys and when the new update is available, you just run a command in discord channel and unfreeze the keys and makes the product available for sale again.
currently it’s monitoring Rust and Cs2 Games.
